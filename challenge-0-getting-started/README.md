# Challenge 0: Getting Started

This folder is a fast-start lane for students.

Goal: get a working ADK project running quickly so challenge time is spent on agent design, not environment setup.

## What's In This Folder

- adk-quickstart.md: Create a minimal ADK project directly with the ADK SDK.
- agents-cli-quickstart.md: Create a deployment-ready ADK project using agents-cli scaffolding.

## Suggested Path

1. If you want the fastest possible first run, start with agents-cli-quickstart.md.
2. If you want to understand the raw ADK building blocks, read adk-quickstart.md next.

## Success Criteria

You are done with Challenge 0 when you can:

1. Start a local playground session.
2. Ask your agent a question and get a response.
3. Modify one instruction in agent code and verify behavior changes.
