# Challenge 6 Solution: ADS Case Study

This folder contains an independent solution project for Challenge 6.

## Goal
Design and deploy an ADK v2 multi-agent system for the Alaska Department of Snow (ADS) with:
- A root routing agent and specialized sub-agents
- MCP integration for backend systems
- RAG grounding over policy/procedure docs
- Google Search for real-time conditions
- Agent evaluation with storm-response test data
- Deployment and registration in Gemini Enterprise

## Scope For This Lab
Keep this project self-contained and runnable on its own.
